FORGE 100 — YOUR TRAINING & NUTRITION APP

Fastest way to use it:
1. Open index.html in a modern browser. The plan, workouts, groceries and tracking work offline.
2. Your entries are saved locally in that browser. Use Settings > Export JSON backup regularly.

To install on an Android home screen as a PWA:
1. Upload all files in this folder (including the icons, manifest and sw.js) to one folder on a HTTPS static host, such as GitHub Pages or Netlify.
2. Open the HTTPS link in Chrome for Android.
3. Choose the three-dot menu > Add to Home screen / Install app.
4. The service worker allows it to open offline once loaded.

No account, external libraries, advertising or network data collection.
This is a training planner, not a diagnostic or medical app. Calorie values are approximate.
